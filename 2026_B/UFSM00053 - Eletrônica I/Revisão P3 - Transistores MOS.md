## Regiões de Operação

| Região |  | | Id | Transcondutância |
| :- | :-: | :- | :-: | :-: |
| Corte | $Vgs < Vth$ | "Aberto" | Id=0 | 
| Triodo | $Vgs >= Vth , Vds< (Vgs - Vth)$ | "Resistor" | Id= \frac{1}{2} \mi Cox \frac{W}{L} |
| Saturação | $Vds >= (Vgs-Vth)$ | "Fonte de Corrente" |

tjb - fonte de corrente controlada por corrente
